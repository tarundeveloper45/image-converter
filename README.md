# Image Converter

A fast, private, in-browser image converter — convert between **JPG**, **PNG**, and **WebP** with a live before/after comparison, quality control, and instant download. Everything runs client-side using the Canvas API; no files are uploaded anywhere.

## Features

- Drag & drop or click to upload an image
- Before/after split-view comparison with a draggable divider
- Convert to JPEG, PNG, or WebP
- Quality slider for lossy formats
- Live file size and percentage savings
- Zoom controls
- One-click download

## Run locally

No build step required — it's a single static HTML file.

```bash
npx serve . -l 5540
```

Then open `http://localhost:5540`.
